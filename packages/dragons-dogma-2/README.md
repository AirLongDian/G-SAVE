# G-SAVE · DRAGON'S DOGMA 2 Support Package

用于 [G-SAVE](https://github.com/AirLongDian/G-SAVE) 的 DRAGON'S DOGMA 2 支持包。

手动配置时选择：

- EXE：`<Steam库>\steamapps\common\Dragons Dogma 2\DD2.exe`
- 存档文件夹：`<Steam目录>\userdata\<Steam账号数字ID>\2054970\remote\win64_save`

应直接选择包含 `data000.bin`、`data001Slot.bin` 的 `win64_save` 文件夹，不要只选择 `remote`。
支持包显示“最近存档”和“旅店存档”两个槽位，并把同目录其他 `.bin` 文件一并纳入历史。

---

DRAGON'S DOGMA 2 support package for [G-SAVE](https://github.com/AirLongDian/G-SAVE).

When configuring paths manually, select:

- EXE: `<Steam Library>\steamapps\common\Dragons Dogma 2\DD2.exe`
- Save folder: `<Steam>\userdata\<Steam account ID>\2054970\remote\win64_save`

Select the `win64_save` folder that directly contains `data000.bin` and `data001Slot.bin`; do not stop at `remote`. The package exposes “Recent save” and “Inn save” slots and tracks the other `.bin` files in the same folder.
