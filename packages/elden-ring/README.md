# G-SAVE · ELDEN RING Support Package

用于 [G-SAVE](https://github.com/AirLongDian/G-SAVE) 的 ELDEN RING 支持包。

自动检测的位置：

- EXE：`<Steam库>\steamapps\common\ELDEN RING\Game\eldenring.exe`
- 存档文件夹：`%APPDATA%\EldenRing`

选择的文件夹内应直接包含 Steam ID 数字目录，数字目录内才是 `ER0000.sl2` 或 `ER0000.co2`。
不要选择数字目录本身。支持包会区分原版和无缝联机，解析各自 10 个槽位、角色名、等级和游玩时间。

---

ELDEN RING support package for [G-SAVE](https://github.com/AirLongDian/G-SAVE).

When configuring paths manually, select:

- EXE: `<Steam Library>\steamapps\common\ELDEN RING\Game\eldenring.exe`
- Save folder: `%APPDATA%\EldenRing`

The selected folder must directly contain numeric Steam ID folders, which then contain `ER0000.sl2` or `ER0000.co2`. Do not select the numeric folder itself. The package distinguishes the original and Seamless Co-op saves and parses 10 slots, character names, levels, and playtime for each.
