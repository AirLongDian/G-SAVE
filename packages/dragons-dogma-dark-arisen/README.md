DRAGON'S DOGMA: DARK ARISEN support package for [G-SAVE](https://github.com/AirLongDian/G-SAVE).

When configuring paths manually, select:

- EXE: `<Steam Library>\steamapps\common\DDDA\DDDA.exe`
- Save folder: `<Steam>\userdata\<Steam account ID>\367500\remote`

Select the `remote` folder that directly contains `DDDA.sav`; do not select `367500` or the save file itself. The current package exposes one “Current progress” slot. Character-name decoding is not yet considered reliable.
