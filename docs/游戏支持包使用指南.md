# G-SAVE 游戏支持包使用指南

## 通用操作

1. 打开 G-SAVE 的“游戏支持”页面。
2. 点击“导入支持包 ZIP”，选择所需游戏的 ZIP。
3. 导入成功后，支持包会显示为卡片。导入本身不会配置游戏，也不会修改存档。
4. 点击卡片。自动检测正确时直接确认；自动检测失败或目录需要修改时选择“手动选择”。
5. 先选择游戏 EXE，再选择下文指定层级的**文件夹**。不要选择单个存档文件。
6. 确认后，G-SAVE 会在该文件夹原地建立 `.git` 历史并创建第一个时间点。

所有新配置游戏的上传时机默认是“退出游戏后”。未连接云端时只建立本地历史，不会上传；
在“云端备份”保存 Git 服务与 Token 后才启用自动上传。

## DARK SOULS III

- 游戏程序：`<Steam库>\steamapps\common\DARK SOULS III\Game\DarkSoulsIII.exe`
- 手动选择存档文件夹：`%APPDATA%\DarkSoulsIII`
- 正确目录形状：

```text
DarkSoulsIII\                 <- 选择这一层
├─ 01100001xxxxxxxx\
│  └─ DS30000.sl2
└─ 01100001yyyyyyyy\          <- 多个 Steam 账号也可同时解析
   └─ DS30000.sl2
```

不要选择账号数字文件夹，也不要选择 `DS30000.sl2` 文件。支持包会解析全部账号的 10 个角色槽位。

## DRAGON'S DOGMA: DARK ARISEN（龙之信条 1）

- 游戏程序：`<Steam库>\steamapps\common\DDDA\DDDA.exe`
- 手动选择存档文件夹：`<Steam目录>\userdata\<Steam账号数字ID>\367500\remote`
- 正确目录形状：

```text
367500\
└─ remote\                     <- 选择这一层
   └─ DDDA.sav
```

不要选择 `367500`、`userdata` 或单个 `DDDA.sav`。当前支持包显示一个“当前进度”槽位、文件大小和更新时间；
角色名尚未解码，因此不会猜测或显示虚假角色信息。

## DRAGON'S DOGMA 2（龙之信条 2）

- 游戏程序：`<Steam库>\steamapps\common\Dragons Dogma 2\DD2.exe`
- 手动选择存档文件夹：`<Steam目录>\userdata\<Steam账号数字ID>\2054970\remote\win64_save`
- 正确目录形状：

```text
remote\
└─ win64_save\                 <- 选择这一层
   ├─ data000.bin              最近存档
   ├─ data001Slot.bin          旅店存档
   └─ data00-1.bin             同样会纳入版本历史
```

不要只选择 `remote`，也不要选择某个 `.bin` 文件。当前支持包显示“最近存档”和“旅店存档”两个槽位；
角色名尚未解码。

## ELDEN RING（艾尔登法环）

- 游戏程序：`<Steam库>\steamapps\common\ELDEN RING\Game\eldenring.exe`
- 手动选择存档文件夹：`%APPDATA%\EldenRing`
- 正确目录形状：

```text
EldenRing\                     <- 选择这一层
├─ 76561198xxxxxxxxx\
│  ├─ ER0000.sl2               原版存档
│  └─ ER0000.co2               无缝联机存档（如已安装）
└─ GraphicsConfig.xml
```

不要选择 Steam ID 数字文件夹。支持包会区分原版 `.sl2` 和无缝联机 `.co2`，并分别解析 10 个槽位、
角色名、等级和游玩时间。`.bak` 与 `GraphicsConfig.xml` 不进入版本历史。

## 通用游戏支持

没有专用支持包时点击“添加其他游戏”：

- 游戏程序选择实际启动游戏的 EXE；
- 存档文件夹选择包含有效存档的最小稳定目录；
- 同一个游戏的多个独立存档根目录可以逐个添加；
- 不要选择临时缓存目录、启动器目录或整个磁盘；
- 通用支持只能显示提交时间、变化文件、大小等信息，不能解析角色槽位。

## 常见问题

- **卡片已导入但没有保护存档**：还需要点击卡片完成路径配置。
- **槽位为空**：最常见原因是选择层级错误。对照上面的目录树重新点击卡片修改。
- **修改目录**：已安装或已配置的卡片一直保留，直接再次点击即可。
- **第一次配置找不到存档**：先运行一次游戏并产生真实存档，再重新检测。
- **云端未连接**：不影响本地 Git 历史；连接后下一次上传会包含之前的本地提交。
