G-SAVE 0.1.0 使用说明
=====================

一、开始使用

1. 解压整个压缩包，不要只单独运行其中一个 EXE。
2. 双击 gsave-gui.exe。
3. 打开“游戏支持”，点击“导入支持包 ZIP”。
4. 从“游戏支持包”目录选择自己需要的 ZIP。导入成功后会出现对应游戏卡片。
5. 点击卡片，专用支持包会自动检测游戏程序与存档文件夹，确认即可。
   没有专用支持包的游戏用「添加无支持包游戏」，此时才手动选择路径。

导入支持包只会把支持包安装到 G-SAVE 的配置目录；点击卡片才会配置游戏路径、
在存档目录中初始化本地版本历史并启动保护。需要修改目录时，直接再次点击卡片。

二、云端备份

新配置游戏默认在退出游戏后上传。尚未连接云端时仍会正常建立本地版本历史，
不会尝试联网；在“云端备份”中填写 Git 服务地址和 Token、测试成功并保存后，
自动上传才会生效。云端测试验证的是账号、仓库创建和访问能力。

三、目录选择

不同游戏必须选择不同层级。请阅读 docs\游戏支持包使用指南.md，里面有每个正式
支持包的目录树和示例。不要直接选择单个存档文件。

四、更新版本

替换程序前先在 GUI 中停止 Core，再关闭 GUI。不要删除游戏存档目录中的 .git，
它保存了本地历史。升级支持包不会删除已有历史。

五、当前支持包

- DARK SOULS III
- DRAGON'S DOGMA: DARK ARISEN（龙之信条 1）
- DRAGON'S DOGMA 2（龙之信条 2）
- ELDEN RING（艾尔登法环，含无缝联机存档识别）

没有专用支持包时可使用内置“添加其他游戏”，但只能记录通用版本信息，不能解析
角色槽位。制作新支持包请阅读 docs\新游戏支持包制作教程.md。

注意：恢复、切换时间线或处理分歧前必须退出对应游戏，并按 GUI 提示停止 Core。
